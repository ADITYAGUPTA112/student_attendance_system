Restoration Test Guide

To restore a downloaded backup into an isolated local or testing environment:

  1. Stop the running application or container.
  2. Place the snapshot into the instance directory:
    cp backup_cloudattend.db instance/cloudattend.db
  3. Verify integrity via the SQLite CLI:
    sqlite3 instance/cloudattend.db "PRAGMA integrity_check;"
  4. Restart the application or Docker container.
